# Guess-the-number
Guess the Number is a fun, interactive game where the computer generates a random number, and the player’s goal is to guess it in as few attempts as possible. This project demonstrates the use of basic programming concepts like loops, conditionals, random number generation, and user input handling.
✨ Key Features

Random number generation within a defined range.

User-friendly prompts to enter guesses.

Feedback provided after each guess (too high, too low, or correct).

Tracks the number of attempts taken to guess the right number.

Option to replay the game after completion.
